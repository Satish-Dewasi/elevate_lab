# Task 1 — Responsive Landing Page

A simple responsive landing page created for the Web Development Internship task.

## Files
- `index.html` — semantic HTML5 structure
- `style.css` — responsive CSS using Flexbox, Grid and media queries

## Features
- Responsive header/navigation
- Hero section with CTA buttons
- Feature cards using CSS Grid
- Responsive layouts for tablet and mobile
- Footer with social links
- No external libraries or paid tools

## How to Run
Open `index.html` directly in Chrome, or use VS Code with the Live Server extension.

## Concepts Used
HTML5, CSS3, Flexbox, CSS Grid, Media Queries, Responsive Design.
